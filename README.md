# Economic Insight — 블로거 테마

깔끔하고 심플한 구글 블로거(Blogger) 커스텀 테마입니다.

- **카테고리(라벨) 없음** — 라벨 관련 UI를 일절 표시하지 않습니다.
- **날짜 중심 분류** — 모든 글을 **연 → 월 → 주 → 일** 계층으로 정리해 한눈에 볼 수 있습니다.
  - 홈/목록 화면: 글 카드가 `2026년 > 7월 > 3주차 > 19일 (일)` 형태의 타임라인으로 그룹핑됩니다.
  - 사이드바 "글 보관함": 전체 글을 같은 연·월·주·일 트리로 펼쳐볼 수 있습니다 (접기/펼치기 지원).
  - 개별 글 상단에도 `2026년 7월 19일 (일) · 7월 3주차` 형태로 날짜가 표시됩니다.
- **개별 글 페이지 정상 렌더링** — 글 목록(홈)·개별 글·정적 페이지·검색·보관함·오류 페이지를 각각 명시적으로 처리하므로, 글을 클릭하면 본문이 정상적으로 열립니다.
- 반응형(모바일 대응), 라이트/다크 모드 자동 지원, 외부 폰트/라이브러리 없이 동작(빠른 로딩).

## 주차 계산 규칙

예측 가능하도록 단순 규칙을 사용합니다: **1~7일 = 1주차, 8~14일 = 2주차, 15~21일 = 3주차, 22~28일 = 4주차, 29일~ = 5주차.**

## 적용 방법 (권장: 복원/업로드)

1. `theme/economic-insight-theme.xml` 파일을 컴퓨터에 저장합니다.
2. [Blogger 관리자](https://www.blogger.com) → 왼쪽 메뉴 **테마** 로 이동합니다.
3. (권장) **맞춤설정 옆 ▼ 버튼 → 백업** 으로 현재 테마를 먼저 내려받습니다.
4. **맞춤설정 옆 ▼ 버튼 → 복원** → **업로드** 를 눌러 1번에서 저장한 XML 파일을 선택합니다.
5. 블로그를 새로고침해 홈 타임라인과 글 클릭 → 본문 열람이 되는지 확인합니다.

복원 메뉴가 안 보이면 **HTML 편집**을 열어 내용을 전체 선택(Ctrl+A) 후 삭제하고 XML 전체를 붙여넣은 뒤 저장해도 됩니다. 저장 시 "위젯을 삭제하시겠습니까?" 확인 창이 나오면 **위젯 삭제(확인)** 를 선택하세요 — 이전 테마의 위젯을 새 테마 것으로 교체하는 정상 과정입니다.

> 이전 테마에 애드센스 코드 등 직접 추가한 스니펫이 있었다면, 적용 후 `</head>` 위에 다시 넣어 주세요.
